# سامانه مدیریت هزینه‌های روزانه

## ۱. معرفی پروژه

سامانه مدیریت هزینه‌های روزانه یک برنامه برای ثبت مخارج روزانه، دسته‌بندی هزینه‌ها و نمایش نمودارهای مالی است که به کاربران کمک می‌کند وضعیت مخارج خود را بهتر مدیریت کنند.

## ۲. مسئله و نیاز کاربران

بسیاری از افراد از میزان هزینه‌های روزانه خود اطلاع دقیقی ندارند و نمی‌توانند به‌راحتی متوجه شوند پولشان در چه بخش‌هایی خرج می‌شود. این سامانه با ثبت و دسته‌بندی هزینه‌ها، امکان بررسی و مدیریت بهتر مخارج را فراهم می‌کند.

## ۳. ویژگی‌های اصلی سامانه

* ثبت هزینه: امکان وارد کردن مبلغ، تاریخ و توضیحات هر هزینه
* دسته‌بندی هزینه‌ها: تقسیم مخارج به دسته‌هایی مانند خوراک، حمل‌ونقل، خرید و تفریح
* نمایش نمودار: نمایش تصویری هزینه‌ها بر اساس دسته‌بندی
* گزارش روزانه و ماهانه: مشاهده مجموع هزینه‌ها در بازه‌های زمانی مختلف
* ویرایش و حذف هزینه: امکان اصلاح یا حذف اطلاعات ثبت‌شده
* مشاهده تاریخچه هزینه‌ها: دسترسی به فهرست مخارج قبلی

## ۴. مخاطبان محصول

* دانش‌آموزان و دانشجویان
* کارمندان
* خانواده‌ها
* افرادی که می‌خواهند هزینه‌های خود را بهتر مدیریت کنند
